# Embedded educational PDF fonts

Unmodified Noto Sans Regular and Bold, from the Noto Project. SIL Open Font
License 1.1 is included in `OFL.txt`; the fonts are embedded in generated PDFs.
The worker loads these local files, without network font requests or OS fonts.

Sources:

- https://raw.githubusercontent.com/notofonts/noto-fonts/main/hinted/ttf/NotoSans/NotoSans-Regular.ttf
- https://raw.githubusercontent.com/notofonts/noto-fonts/main/hinted/ttf/NotoSans/NotoSans-Bold.ttf
- https://raw.githubusercontent.com/notofonts/noto-fonts/main/LICENSE
