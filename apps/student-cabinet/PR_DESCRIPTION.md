# STU-12: кабинет ученика с реальными API

Вместо экрана проверки доступа ученик получает адаптивный кабинет: dashboard,
уроки, перенос через менеджера, ДЗ с черновиком/файлами/версиями, навыки,
материалы, информационный абонемент, уведомления и настройки безопасности.
Прямые ссылки работают отдельно от текущей страницы списка. Доступ и возможность
войти в Meet определяет сервер; финансовых команд в кабинете нет.

Новый workspace `apps/student-cabinet`, React/Vite, TanStack Query v5, Zustand для
меню. Существующая сборка одного Vercel-проекта дополняется статическим `/student`.
Добавлены три student-scoped GET проекции и bootstrap timeZone/контакты;
OpenAPI/SDK обновлены. Новые БД, миграции или окружения не создаются.

Мобильная bottom navigation и брейкпоинты следуют заданию/10.2/B. Видеокадры —
запись экрана с наложенным звонком, а не доказательство готовой мобильной вёрстки.
Модальные окна используют native dialog, Escape/focus trap и восстановление фокуса;
переходы статусов не анимируются без доказанного требования, reduced-motion учтён.

## Валидация

- Адресные TypeScript/Vite build кабинета и QA-оболочки; ESLint изменённого scope.
- 157 unit/Nest HTTP тестов затронутых контекстов и read/write контрактов с mock Prisma.
- 12 Playwright сценариев: полный путь входа/смены пароля/ДЗ/баланса, draft debounce
  и reload, slow saves, upload/confirm/submit retry, периоды/перенос, canJoin,
  402/403, read-all, native modal и viewport 360/390/820/1600.
- Lighthouse Accessibility 100 на 14 маршрутах с локальным синтетическим API.

Рабочий DB/S3/email E2E, ручная приёмка и общие gates остаются открыты.
Deploy/migrate на рабочем проекте не выполнялись. Предыдущие доказательства заморожены.
