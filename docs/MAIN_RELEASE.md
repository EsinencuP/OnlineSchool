## Состав

- Локальная основа: `3e7e83f`, `D:/OnlineSchool`, включая исходники, документацию,
  `ref/`, `template/`, регламенты `deliverables/` и локальные отчёты `output/`.
- Проверенные дополнения: `codex/manager-vercel` / `49bac15`: вход по паролю всех
  ролей, переходы QA в оба кабинета, демо-данные и исправление SELECT для карточки.
- Удаление видео владельцем сохранено. Большое видео и удалённый RAR из старой
  локальной истории не входят в новую историю main. Локальная исходная ветка
  сохраняется; force push не требуется.
- Полная история удалённого main и реализованных ученических/менеджерских задач
  сохраняется через родительскую ветку `codex/manager-vercel`.
- Существующие миграции взяты побайтно из развёрнутого `49bac15`. У локальных
  копий были только отличия LF/CRLF; менять checksums применённых миграций нельзя.
- Данные БД, переменные окружения, ключи, `.git`, `node_modules`, кэши, dist и
  временные браузерные файлы не являются исходниками и не публикуются.

Отдельная `chore/repo-cleanup` содержит альтернативный рефакторинг ядра и сборки
от старого main. Его runtime-изменения не подменяют объявленную владельцем рабочую
реализацию кабинетов. Ветка сохраняется отдельно; её прежние результаты не
выдаются за тестирование объединённой версии.
