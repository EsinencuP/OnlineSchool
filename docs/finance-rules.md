# Деньги, абонементы и возвраты

Базовая цена стандартного занятия — 350 MDL. Для конкретного оплаченного права учитывается цена, зафиксированная при покупке с применимой скидкой.

## Поступления и оплаченные права

| Решение | Правило |
| --- | --- |
| **PAY-01** | **Единственный способ оплаты обучения — банковский перевод на официальный банковский счёт академии по реквизитам менеджера. Факт оплаты подтверждается банковской выпиской академии. Наличные, эквайринг, электронные кошельки и альтернативные каналы не допускаются.** |
| **11.3.1** | Раздельный учёт денежных поступлений, остатка предоплаты/обязательств предоставить занятия и заработанного управленческого дохода по использованным в установленном порядке оплаченным правам. При переносе и заморозке право не расходуется. Поздняя отмена отражается отдельным основанием от реально проведённого занятия. Проданная цена пакета, включая скидки, является основанием для распределения стоимости использованных/оставшихся прав. |
| **11.3.2** | При подтверждённом правомерном основании возврата его расчёт производится исходя из фактически оплаченной цены неиспользованных прав. Первоначальная скидка на уже правомерно использованные права сохраняется; задним числом не пересчитывать их по стандартной цене. Сам расчёт не означает автоматическое одобрение, а клиентские права, исключения и финансовые корректировки определяются применимыми правилами Part I/II и договором/законом. |
| **11.3.3** | Менеджер сверяет права и готовит проект. Любую окончательную сумму возврата утверждает руководитель. Исполнение перевода и его подтверждение учитываются отдельно. |
| **11.3.4** | Отдельный жизненный цикл возврата. Одобрение создаёт отражаемое обязательство вернуть деньги и сохраняет связь с исходными оплаченными правами; фактическое исполнение отмечается только после подтверждённого перевода. Ожидание, ошибки, задержки и отказ учитываются раздельно, неудачная попытка не означает выплату. Контроль доступа, аудит и защита от повторного возврата обязательны. |
| **11.3.5** | Поштучный учёт уникальных исходных оплаченных прав с привязкой к абонементу и событиям. CRM подготавливает предварительную ведомость, менеджер проверяет, спорные и отнесённые Part I/II к руководителю случаи эскалируются. Переносы и заморозки не создают новых прав и не списывают существующие сами по себе. Расчёт суммы — строго по №11.3.2/A. |
| **11.3.6** | Раздельные оплаченные права и их подтверждённая фактически распределённая стоимость по каждому предмету/образовательному назначению. При прекращении одного предмета возврат рассчитывается только по его правомерно неиспользованным правам; права, скидки и условия продолжающихся предметов не пересчитываются. Для единого межпредметного пакета без доказанного распределения общей цены требуется отдельное согласованное решение; автоматическое произвольное распределение запрещено. Частичный доступ к кабинету ученика — отдельная зависимость. |
| **11.3.7** | В новых комбинированных пакетах общая скидка распределяется пропорционально исходной стоимости предметных компонентов до скидки. Суммы и цена оплаченных прав фиксируются при покупке для дальнейших возвратов; неизменность исходных условий для старых неоднозначных сделок. Точное распределение денежных дробей/округления до банов — в ТЗ. |
| **11.3.8** | При рассрочке фиксируются согласованные график взносов, цена и скидка. Пока суммарная подтверждённая оплата абонемента ниже полной цены, каждый допуск требует отдельного ограниченного решения руководителя. |
| **11.3.9** | Менеджер заранее согласует с семьёй распределение взноса по конкретным правам и предметам по исходным ценам. При неполной оплате действуют отдельные директорские допуски. При полной совокупной оплате действуют обычные оплаченные права без дублирования. |
| **11.3.10** | При просрочке очередного взноса менеджер лично согласовывает с семьёй новый график только будущих неисполненных платежей и документирует изменения. Сохраняются подтверждённые ранее оплаты, активированные права, исходная цена и правомерные преимущества долгосрочного пакета; нет автоматического аннулирования скидки, штрафа, продления срока абонемента или создания заморозки. Без оплаты новые права не активируются. Споры и исключения за пределами полномочий менеджера — руководителю; договорные обязательства и нормы права учитываются отдельно. |
| **11.3.11** | **Каждое** досрочное прекращение рассрочки, включая типовое, **утверждает руководитель** на основании подготовленной менеджером полной сверки: поступления, правомерно использованные права, сохранённые/неиспользованные оплаченные права, нераспределённые авансы и ещё не поступившие будущие платежи. Расчёт возврата — по №11.3.2/A, исполнение — по №11.3.3–11.3.4. Не аннулировать и не взыскивать будущие взносы автоматически: исход определяют договор, применимое право и решение в пределах полномочий. |
| **11.3.12** | Нераспределённый остаток реально полученной предоплаты, недостаточный для целого оплаченного урока, учитывается как отдельное денежное обязательство без автоматического сгорания, признания доходом или назначения. Семья и менеджер согласуют допустимый зачёт в новый абонемент/предмет; правомерный возврат проходит №11.3.2–11.3.4; при досрочном прекращении рассрочки требуется решение руководителя по №11.3.11/C. Один частично оплаченный урок не активируется. |
| **11.3.13** | Банковские отзывы, оспаривания и ошибочно подтверждённые зачисления обрабатываются отдельными финансовыми записями и обязательной сверкой менеджера, с эскалацией исключений руководителю. Начавшийся спор и окончательно подтверждённый отзыв различаются. История реально проведённых уроков и преподавательских начислений не стирается; будущие неоплаченные права проверяются до урока; нет автоматического долга семьи, освобождения слота и переписывания закрытого периода. |
| **11.3.14** | Автоматическое сопоставление фактически подтверждённых входящих платежей только при достоверном уникальном идентификаторе и однозначном ранее согласованном назначении; неоднозначные/неопознанные платежи отдельно учитываются до документированной проверки менеджера без активации прав. Повторные уведомления об одной операции не дублируют деньги или права; два отдельных реальных перевода не объединяются только по совпадению суммы. |
| **11.3.15** | Активировать уникальные полностью оплаченные права лишь после подтверждения **банковского перевода по официальной выписке банковского счёта академии**, однозначной идентификации и согласованного распределения. Скриншот клиента без банковской выписки — вспомогательный материал, не основание активации. Другие каналы оплаты обучения, включая наличные и платёжных провайдеров, не допускаются. |
| **11.3.16** | **Банковские комиссии при PAY-01:** отдельные показатели подтверждённой полной суммы перевода, фактического зачисления и документально подтверждённой комиссии. Подтверждённая комиссия за счёт академии — отдельный расход, а не недоплата ученика. Комиссия отправителя, взятая отдельно сверх суммы перевода, не уменьшает оплату обучения. Необъяснённые расхождения рассматривает менеджер; нельзя признать деньги полученными и открыть права лишь по предположению. |
| **11.3.17** | Регулярная, предпочтительно каждый доступный банковский день, автоматизированная сверка **официальной выписки академии** с операциями CRM (поступления, исходящие возвраты, подтверждённые комиссии, отзывы/сторно); загрузка файлом или разрешённым банковским каналом; несоответствия проверяет менеджер, подтверждает уполномоченный финансовый сотрудник при необходимости. Не поступившая выписка не считается сверенной; исключения в ведомости закрытия с руководительским решением по Part II №9.9. Правила классификации банковских комиссий утверждены отдельно в №11.3.16/B. |
| **11.3.18** | Проверенный получатель исходящего банковского возврата, независимая проверка новых/изменённых реквизитов, дополнительное согласование руководителя при смене бенефициара или переводе третьему лицу при допустимом документальном основании; отдельный банковский исполнитель. Статус «Выплачен» — только после подтверждения банка/выписки. Ошибка перевода не погашает обязательство; повторная попытка без дубликата. При досрочном прекращении рассрочки действует специальное обязательное решение руководителя №11.3.11/C. |

## Начисления и обязательства

| Решение | Правило |
| --- | --- |
| 11.2.1 | Уникальные закреплённые ученики с подтверждённым оплаченным правом; исключения заморозки по утверждённой модели |
| 11.2.3 | Учёт начислений поурочно с помесячной агрегацией; кабинет «Мои финансы» |
| 11.2.4 | Ученик в официальной оплаченной заморозке продолжает учитываться для KPI, пока право сохраняется |
| 11.2.7 | Глобальные KPI меняет руководитель перспективно, с версиями и аудитом |
| 11.2.8 | Руководитель задаёт индивидуальное условие оплаты с основанием и сроком действия, с аудитом; приведено в модель гарантированной ставки №11.2.13 |
| 11.2.9 | При ранее обещанных скидках и KPI, превышающих номинальный резерв 50 MDL, обязательства сохраняются, отклонение маржи учтено |
| 11.2.10 | Снимок применимых KPI в момент фактического начала урока; начисление при допустимом факте проведения |
| 11.2.11 | Проверяемые ретрокоррекции ошибочных KPI отдельной операцией, аудит; обязательный контроль руководителя именно для таких KPI-коррекций |
| 11.2.12 | Лимит контролируемых отклонений 5% от плановой защищённой месячной маржи, предупреждения 50/80/100%, новые дискреционные условия по бюджету; обещанные обязательства не отменяются |
| 11.2.13 | Индивидуальная гарантия **минимальной ставки за оплачиваемый урок**, топ-ап до порога, в обычном режиме потолок 250 MDL; ранее безусловно обещанные надбавки не меняются молча |
| 11.2.14 | Замещающий получает персональную ставку по своим KPI |
| 11.2.15 | Пропорциональная модель там, где допустима оплата части урока; **не применяется универсально к техническим сбоям** вопреки §3.16 Part I |
| 11.2.16 | Правило своевременной отмены = 0; **стандартная поздняя отмена ученика = 200 MDL без бонусов по Part I §3.4 и Part II §9.2**; не 250 MDL |
| 11.2.17 | Предварительный финансовый расчёт неполного урока системой, подтверждение менеджером доначисления после восполнения минут, без минутного кошелька |
| 11.2.18 | Четыре финансовых показателя в кабинете: начислено / ожидает проверки / утверждено к выплате / фактически выплачено; отдельные детали операций |
| 11.2.19 | Каждый оставшийся спор рассматривает руководитель до закрытия месячной ведомости; допускается документированное решение оставить кейс на дополнительной проверке; запись не пропадает |

## Расходы и отчётность

Содержательные правила утверждены. Формальное закрытие раздела 11.4 ожидается.

| Решение | Правило |
| --- | --- |
| **11.4.1** | Разделение расходов по экономическому поведению на постоянные, переменные и разовые с аналитикой по предметам, занятиям и направлениям, когда отнесение обоснованно |
| **11.4.2** | Двухконтурный управленческий учёт: расходы по относящемуся периоду отдельно от фактических платежей/денежного потока |
| **11.4.3** | Хостинг и вся реклама — общие расходы академии без распределения по предметам, направлениям или отдельным урокам, включая предметную рекламу |
| **11.4.4** | Каждый расход на хостинг и рекламу требует отдельного предварительного утверждения руководителем; учёт план/факт и банковского исполнения |
| **11.4.5** | Контролируемый расчёт доступной ликвидности с учётом обязательств и будущих денежных потребностей; индивидуальное согласование каждого платежа руководителем сохраняется |
| **11.4.6** | Скользящий прогноз денежных потребностей на 30 календарных дней и отдельный защитный денежный остаток, задаваемый руководителем; предупреждение о нарушении буфера |
| **11.4.7** | Комбинированный защитный остаток: большее из фиксированного минимума и доли 30-дневного прогноза выплат |
| **11.4.8** | Ежемесячный необязательный план-факт по хостингу и рекламе: план, утверждённые платежи, фактические денежные списания, расходы периода и отклонения; ни план, ни остаток плана не разрешают трату без отдельного одобрения руководителем |
| **11.4.9** | Трёхуровневая управленческая отчётность: академия целиком; предметы; **преподаватели**. Прямой финансовый вклад отделяется от полной прибыли; без изменения начислений и распределения общих расходов |
| **11.4.10** | **Не учитывать вовсе** расходы/вложения на разработку и модернизацию собственной платформы в управленческой экономике, калькуляциях прибыли, бюджетах хостинга/рекламы и показателях предметов/преподавателей; фактические банковские движения при их наличии остаются под обязательной сверкой |
| **11.4.11** | Отдельная аналитика фактических выплат владельцу/собственнику по надлежащему основанию; как правило, не уменьшать операционный результат за счёт распределения прибыли или выплаты капитального характера, но отражать денежное движение и доступную ликвидность; юридическую классификацию проверять по документам |
| **11.4.12** | Динамическая точка безубыточности и условный прогноз минимального объёма занятий на базе заработанной выручки, реальных начислений преподавателям и фактических общих расходов, с учётом событий Part I/II, без выдуманных расходов |
| **11.4.13** | Двухконтурное сценарное планирование роста: подтверждённая текущая база учеников/расписания/оплаченных прав и отдельные гипотезы руководителя об учениках, частоте занятий, составе преподавателей, скидках и рекламе; расчёт сценарного финансового результата без признания его фактом |
| **11.4.14** | Регулярный предварительный план-факт, доступный для еженедельного просмотра; итог после закрытия календарного месяца, анализ доказуемых причин отклонения, неизменность исходного снимка прогноза |
| **11.4.15** | Минимальная ролевая финансовая панель: руководитель — полная аналитика; менеджер, преподаватель, семья — только необходимые им рабочие/собственные данные; базовая отчётность без нового сложного экспорта, гибких делегаций и дополнительных универсальных уведомлений |

По фактически проведённому неоплаченному уроку менеджер собирает сведения и передаёт их руководителю для индивидуального финансового решения. Основание возврата проверяют отдельно. Юридические условия, округление, документы, сроки и автоматизация возврата остаются открытыми.
