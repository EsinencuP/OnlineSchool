# Reference patterns

Sources are public help pages found via web search on 2026-11-27; product UIs themselves were not opened (no accounts). Claims marked "unverified" came from search summaries only.

| Product | Pattern | Problem it solves | Use here | Source |
|---|---|---|---|---|
| Attio | Record page with relationship tabs; table and kanban views of the same records; saved views | One entity, many contexts | Lead kanban + student table + drawer; director tables per entity | attio.com/help/reference/managing-your-data/records/create-and-view-records, …/attributes/relationship-attributes |
| Linear | Filters narrow, display options arrange; main filters in the URL; favourited views in sidebar | Shareable, restorable list state | All list filters in URL params (`status`, `kind`, `ready`, `teacher`, `view`) | linear.app/docs/filters, linear.app/docs/display-options |
| Stripe Dashboard | Home shows analytics plus "actions needed" (disputes etc.); charts labelled as estimates | Overview that leads to action | Director overview: decisions queue + escalations next to KPIs; "Данные на HH:MM" | docs.stripe.com/dashboard/basics; support.stripe.com dashboard home charts |
| Mixpanel | Funnels count users who complete steps in order within a window; breakdown by property | Honest conversion | Stage counts shown as a snapshot, not a funnel; conversion only as created→converted in 30 d | docs.mixpanel.com/docs/reports/funnels/funnels-faq |
| HubSpot | Task queues worked back-to-back; prospecting queue from the sales workspace | Operator throughput | Manager "Требует внимания" with the action on each row | knowledge.hubspot.com/tasks/use-task-queues |
| Teachworks | Teacher calendar with Day/Week views; employee filter; colour by teacher/student/service | Read one teacher's load | Teacher chips + Day (teachers as columns) / Week view | intercom.help/teachworks… resource-calendar-views; teachworks.com/features/calendar |
| TutorCruncher | Calendar filtered/coloured by tutor, client, status; month view on mobile (unverified) | Status at a glance | Status on block edge, trial on fill; month view left to the mini-calendar | help.tutorcruncher.com/en/articles/14183116-calendar |
| Notion Calendar | Multiple calendars in one view, hide/show calendars | Overlay of several schedules | Not adopted: overlapping 6 teachers in one week is unreadable; resource columns used instead (overlay behaviour unverified) | notion.com/help/guides/getting-started-with-notion-calendar |
| dashboard-design skill (school case study) | KPI → attention on data → action beside it; classed tiers; no sentences under numbers | Report-like dashboards | KPI cards with one-line context, warm only for problems | .claude/skills/dashboard-design/references/case-study-school-dashboard.md |
