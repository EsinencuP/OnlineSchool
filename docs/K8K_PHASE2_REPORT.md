# K8K — оболочка и состояния, фаза 2

03.11.2026. Opt-in реализация; приёмка и production GO не заявляются. База — аудит 1efd4c8 поверх main 5f3c6f0. Прежний локальный preview сохранён отдельно в `.codex/k8k-before-phase2`; его экранные переработки не включены.

## Результат

- Единый packages/ui: AppShell, Sidebar, BottomNav, Header, NotificationBell, стабильная конфигурация пяти ролей. URL ученик/менеджер и локальные staff-вкладки сохранены. Нет пунктов «Сообщения»/«Написать менеджеру»; у ученика уведомления только из колокольчика. Для остальных ролей без unread API фиктивного счётчика нет.
- Sidebar от 1024 px, BottomNav ниже; немодальное меню с клавиатурой/Escape/возвратом фокуса. Поиск менеджера доступен на 360 px. Дополнительные календарь/абонемент/контакты ученика доступны и на промежуточных ширинах.
- StateBoundary: loading, empty, ready, stale, error, pending/unknown-result, forbidden, subscription-limited, session-expired. Стабильный контейнер сохраняет DOM/ввод при обновлении. При отказе доступа/сессии children не рендерятся; частичное ограничение не закрывает остальные предметы. Компонент не вычисляет оплаченные права.
- FreshnessLabel: последняя успешная загрузка, неизвестность, часовой пояс; stale при ошибке/офлайне/возрасте оперативной проекции. Загрузка не считается подтверждением финансового действия.
- Возврат/focus/online и периодическое чтение активной вкладки; без перемещения модулей/фокусировки из data-effect. Ввод, открытый диалог/аккаунт откладывают новые чтения, окончание ввода возобновляет отложенное. Auth-read и успешная post-command invalidation сохранены.
- Слот одного критического события и всей очереди со счётчиком реализован. **Продуктовый priorityEnabled=false**: в текущих DTO нет авторитетной критичности/выбора primary. Блок скрыт по правилу 3; dueAt/overdue не объявлены критичностью; новый API не создавался. Синтетический пример есть только в компонентном fixture.
- `?ui.k8k=1` включает новый вид, `?ui.k8k=0` — прежний. SessionStorage текущего origin; при закрытом storage работает прямой URL. Старый код сохранён до приёмки. Dev URL менеджера: `/manager/?ui.k8k=1` с завершающим `/`.

## Границы и открытые решения

API/OpenAPI/SDK, сервер, миграции/БД, денежные формулы, CSRF/idempotency, обработчики 401/403, словарь ошибок, одноразовый пароль и права не изменены. Frontend api-файлы меняют только политику чтения/метаданные query. Граница распознаёт запрет для отображения, не заменяет авторизацию.

Фаза 1 целиком **не выполнялась и не закрывается**: создана минимальная основа фазы 2. Полный Radix/UI-kit, Storybook, culori, Stylelint и их gate остаются задачами фазы 1. Доменные формы/диалоги не переписывались; pending/unknown-result/subscription-limited поддержаны типами и тестами, но новые серверные причины их включения не придуманы.

Точные интервалы VIS-06 открыты. Рекомендация за ui.k8k: 60 секунд — оперативные чтения, 15 — открытая карточка урока ученика, 120 — предупреждение возраста оперативной проекции. Опубликованные навыки/финансы/архив не получают новый периодический опрос; auth-read и предметный polling статуса уведомлений менеджера сохранены. Это не бизнес-таймеры/SLA.

Предметное содержимое кабинетов сохранено. Из нового вида дополнительно исключена общая progress-шкала знаний по UX-AUD-01. Миграция остальных карточек/таблиц и устранение baseline-дефектов — ролевые фазы. Полный WCAG AA исторических экранов не заявляется.

Только fixtures/MSW, внешние запросы заблокированы. [Результат](../output/k8k-phase2/browser.json), [матрица](../output/k8k-phase2/INDEX.md).

- React-проверка по vercel:react-best-practices: стабильные ключи/контейнер данных, общие network listeners, read-only refresh, статические иконки, отсутствие бизнес-команд в primitives. Запрет CSS-фреймворков сохранён.

В harness исправлены Vite base URL и явный browser context для axe.
