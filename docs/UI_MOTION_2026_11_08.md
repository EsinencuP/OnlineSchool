# Движение в интерфейсе K8K

Решение владельца от 08.11.2026 для пяти кабинетов, общего входа и общих компонентов. Дополняет [правила визуального упрощения](UI_VISUAL_SIMPLIFICATION_2026_11_08.md). Движение объясняет действие и не добавляет декор. Первая фраза «Use is out for entrances» интерпретирована как ease-out для появления.

| Правило                            | Применение                                                                                                                                                                                                       |
| ---------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Ease-out для появления             | `--k8k-motion-out`: cubic-bezier(0.16, 1, 0.3, 1)                                                                                                                                                                |
| Dropdown 150–250 мс                | Появление 200 мс, закрытие 160 мс; задержка показа tooltip — отдельное свойство                                                                                                                                  |
| Каскад строк 30 мс                 | Общие списки и DenseTable. Первые 10 строк: 0…270 мс, остальные не ждут дольше 270 мс. Изменение данных не задерживается                                                                                         |
| Нажатие кнопки 0.97                | Только доступные кнопки и ссылки-действия; scale не меняет размеры области нажатия в раскладке                                                                                                                   |
| Движущаяся ручка +12%              | Для будущих switch/slider: растяжение по оси движения до 1.12 с возвратом к 1. Сейчас таких ручек нет; нативные radio и select не подменяются                                                                    |
| Детали появляются каскадом         | Содержимое overlay получает задержки 30 и 60 мс, пока поверхность занимает место; сфокусированное содержимое без задержки                                                                                        |
| Объекты движутся по дугам          | Для переноса объекта между местами использовать кривую траекторию. В текущих компонентах такого переноса нет; небольшое появление строки не превращать в перелёт                                                 |
| Пульс подтверждает успех           | Один пульс иконки только у Toast с outcome=confirmed и tone=success. Pending, queued и unknown не получают подтверждение успеха                                                                                  |
| Ease-in-out для движения на экране | `--k8k-motion-move`: cubic-bezier(0.4, 0, 0.2, 1); применяется к нажатию и пульсу                                                                                                                                |
| Popover начинается с 0.95          | Начальный масштаб 0.95, конечный 1                                                                                                                                                                               |
| Появление от триггера              | Popover/Menu/Tooltip используют origin Radix с учётом расположения. Dialog/Drawer и меню аккаунта измеряют источник до смены фокуса                                                                              |
| Уход к триггеру                    | При закрытии сохраняется тот же origin. Программное открытие без источника использует верхнюю кромку                                                                                                             |
| Без растворения в центре           | Поверхности меняют масштаб от источника; отдельный fade применяется лишь к модальному затемнению и сменяемым иконкам                                                                                             |
| Без spring bounce                  | Обычные переходы используют фиксированные easing-кривые без пружин и отскока                                                                                                                                     |
| Не tween ручную анимацию           | Для будущих покадровых или снятых с рук материалов сохранять авторский тайминг. Таких материалов в кабинетах сейчас нет                                                                                          |
| Выход короче на 20%                | 160 мс против 200 мс появления                                                                                                                                                                                   |
| Новое входит, пока старое уходит   | В Tabs при keep-mounted обе фазы запускаются вместе. Уходящий panel inert и aria-hidden, черновик не размонтируется. Явный unmount-inactive сохраняет прежний контракт                                           |
| Маска для раскрытия и смены цвета  | Раскрытие деталей, строк и вкладок использует clip-path. Новые анимированные смены цвета выполнять маской отдельного слоя; сейчас цвет статусов и выбора меняется сразу, без промежуточных оттенков              |
| Crossfade иконок с scale и blur    | IconSwap для изменения значения внутри одного контрола; меню оболочки меняет menu/close. Статические Icon не получают лишние обёртки                                                                             |
| Rubber band за границами drag      | Для будущего перетаскивания отделять положение указателя от ограниченного значения, добавлять затухающее сопротивление за границей и возвращать объект внутрь. Текущие списки и канбан не объявляются draggable  |
| Общий layout ID у одного объекта   | При будущем переходе общей сущности между представлениями использовать один стабильный ID из типа и ID сущности, например lesson:<id>, а не индекс строки. Сейчас shared-layout переходов и движка layout ID нет |

Реализация: `packages/ui/src/motion.css`, `motion.ts`, общие overlay, Tabs, IconSwap, DenseTable, оболочка и меню аккаунта. Новых зависимостей нет. Для native details анимированное закрытие использует поддержку дискретного content-visibility; при её отсутствии остаётся штатное мгновенное закрытие.

При prefers-reduced-motion: reduce движение, задержки и blur отключены; результаты действий, статусы, фокус и keyboard navigation сохраняются. Права доступа, смена сессии, скрытие запрещённых данных и отправка команд не ждут анимации. Не сохранять старые приватные данные ради перехода. Не анимировать всё заново при каждом обновлении серверного времени.

Проверки и снимки: [локальный отчёт](../output/ui-motion-2026-11-08/report.md). Эти правила не закрывают будущие функциональные TASK и не означают приёмку всей платформы.
