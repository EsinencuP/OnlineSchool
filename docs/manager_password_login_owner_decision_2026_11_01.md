# Временный вход менеджера по паролю

Решение владельца от 01.11.2026: отключить обязательный passkey для кабинета
менеджера до финального этапа релиза и опубликовать изменение на существующем Vercel.

`MANAGER_PASSWORD_ONLY_LOGIN=true` разрешает password-only сессию только активному
STAFF с единственной ролью MANAGER на маршрутах кабинета менеджера.
Режим по умолчанию выключен. Для восстановления обязательного passkey выставить
значение `false` (или удалить переменную) и выполнить production deployment.

Фактическое поле `mfa_verified_at` не изменяется; `mfa_completed` остаётся false.
Ответ сессии содержит `manager_password_only: true`, по которому форма входа
открывает кабинет. Настоящий passkey и зарегистрированные ключи сохраняются.
Сессии восстановления, остальные роли, общие staff/Finance API и маршруты с
явным RequireMfa по-прежнему требуют прежнюю аутентификацию.
Проверки портфолио, деактивации, отзыва сессий, CSRF и идемпотентности сохранены.
