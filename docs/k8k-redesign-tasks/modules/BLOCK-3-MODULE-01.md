# Блок3 — Предметы, права и абонементы

Модуль выполняется отдельными заданиями по порядку. Этот индекс не заменяет текст TASK; каждый файл содержит собственный контекст и правила.

- [TASK-024 — Серверная проекция предметов, доступа и абонементов ученика](../TASK-024.md). Исходно: Не реализовано: текущий API выбирает один абонемент; subjectSubscriptions=false. Серверные правила допуска и ledger существуют и должны переиспользоваться.
- [TASK-025 — Предметный хаб, навигация и помощь ученику](../TASK-025.md). Исходно: Частично: AppShell и ролевое меню есть; отсутствуют «Мои предметы» и «Помощь», новая главная имеет большие пустые зоны и не содержит предметных карточек.
- [TASK-026 — Абонементы по каждому предмету и точные детали прав](../TASK-026.md). Исходно: Частично: SubjectSubscriptions view-компонент и single-subscription detail есть, но основной блок выключен; histories читаются существующими API.

Выход модуля: критерии каждого TASK и доступные по ссылкам отчёты; gate не считается пройденным по наличию исходного кода.
