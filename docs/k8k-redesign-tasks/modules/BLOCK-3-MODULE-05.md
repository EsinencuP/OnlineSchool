# Блок3 — События, локализация и приёмка

Модуль выполняется отдельными заданиями по порядку. Этот индекс не заменяет текст TASK; каждый файл содержит собственный контекст и правила.

- [TASK-033 — Колокольчик событий: завершение пагинации, прочтения и переходов](../TASK-033.md). Исходно: Частично реализовано root: поповер имеет pages/read-all, /notifications в K8K ведёт на /student?events=1, report deep link добавлен. Требуются полная локализация/доступность, актуальные scope/late-response сценарии и источники без вымышленных событий.
- [TASK-034 — Полная RU/RO локализация, материалы, профиль и безопасность](../TASK-034.md). Исходно: Частично: locale ru/ro и переведённые nav/freshness/reports уже есть. Materials/profile/security/password/suspended, ошибки и aria требуют полного перевода.
- [TASK-035 — Приёмочный gate ученического кабинета K8K](../TASK-035.md). Исходно: Не выполнено для полного нового scope: есть исторические STU-12/phase2/phase3 и новый root smoke отчёта/колокольчика. Они не доказывают завершение TASK-024…034 или всей академии.

Выход модуля: критерии каждого TASK и доступные по ссылкам отчёты; gate не считается пройденным по наличию исходного кода.
