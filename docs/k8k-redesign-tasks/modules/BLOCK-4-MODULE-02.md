# Блок4 — Выдача и проверка домашних заданий

Модуль выполняется отдельными заданиями по порядку. Этот индекс не заменяет текст TASK; каждый файл содержит собственный контекст и правила.

- [TASK-039 — Преподаватель: серверные команды создания задания, выдачи и разрешённых материалов](../TASK-039.md). Исходно: HomeworkAssignment/Delivery/Submission/Review, attachments, S3 и student homework поток существуют. EducationModule пуст. Platform workspace читает issued_by заголовки, но собственных teacher команд создания/выдачи нет. Student hwId — именно HomeworkDelivery.id, не общий assignmentId.
- [TASK-040 — Преподаватель: очередь отправленных работ и версионированная проверка без оценок](../TASK-040.md). Исходно: Существуют HomeworkSubmission.version, supersedes_submission_id и SubmissionReview с результатами ACCEPTED/NEEDS_REVISION и собственной version. Student service читает эти факты и шлёт версионированные исправления; teacher queue/review commands пока отсутствуют.
- [TASK-041 — Преподаватель: интерфейс выдачи, единой очереди и проверки ДЗ в контексте урока и ученика](../TASK-041.md). Исходно: Teacher homework view в App.tsx выводит заголовки выданных работ. Рабочих форм выдачи/проверки и собственной очереди ещё нет. TASK-039/040 поставляют реальные команды; student homework editor уже имеет действующие autosave/submit правила и должен остаться совместимым.

Выход модуля: критерии каждого TASK и доступные по ссылкам отчёты; gate не считается пройденным по наличию исходного кода.
