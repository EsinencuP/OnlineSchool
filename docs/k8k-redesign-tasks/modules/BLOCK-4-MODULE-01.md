# Блок4 — Уроки, собственный контекст и расписание

Модуль выполняется отдельными заданиями по порядку. Этот индекс не заменяет текст TASK; каждый файл содержит собственный контекст и правила.

- [TASK-036 — Преподаватель: серверный контекст, доступ к собственным объектам и детализация урока](../TASK-036.md). Исходно: Частично: PlatformController.workspace отдаёт общую read-only витрину teacher/director с лимитом 100 уроков и 50 выданных ДЗ. TeacherAccount и TeachingAssignment существуют. Отдельных полных teacher read-моделей, безопасной детализации урока и контекстной образовательной карточки пока нет.
- [TASK-037 — Преподаватель: K8K «Сегодня», недельное расписание и единая карточка урока](../TASK-037.md). Исходно: В apps/platform/src/App.tsx есть обзор, список расписания, назначенные ученики и заголовки выданных ДЗ. Это одна read-only витрина, без полноценной карточки, недельного календаря и педагогических действий. Общие компоненты K8K создаются предыдущими блоками.
- [TASK-038 — Преподаватель: подключить фактическое начало и версионированный результат урока, сохранить срок24ч](../TASK-038.md). Исходно: Существуют OutcomesService.start/report/confirm, TeacherRateService.snapshotAtStart, ScheduleDeadlines и teacher команды ScheduleController. Report версионируется; окончательное подтверждение выполняет manager/director. Teacher UI не подключает эти операции; отдельного универсального API журнала нет.

Выход модуля: критерии каждого TASK и доступные по ссылкам отчёты; gate не считается пройденным по наличию исходного кода.
