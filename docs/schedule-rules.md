# Расписание, замены и отмены

## Назначение занятий

| Параметр | Утверждённое значение |
|---|---|
| Режим подбора | Рекомендации алгоритма + финальное решение менеджера |
| Время жизни временной брони | **12 часов** |
| Автоматическое продление брони | **Нет** |
| Бронирование нескольких слотов | **Атомарно, одним набором** |
| Начало регулярного расписания | Назначает менеджер |
| Стандартная продолжительность шаблона | **Без конечной даты** |
| Постоянное изменение графика | **Со следующего понедельника** |
| Разовые отклонения | Отдельные исключения без изменения недельного шаблона |
| Приоритет при коллизии будущего слота | Ранее окончательно подтверждённое назначение |
| Перерыв между уроками | Предпочтение преподавателя, допускается **0 минут** |
| Дневной / недельный предел | Настраивается преподавателем; допускается согласованное исключение |
| Запрет пересечения уроков | **Безусловный** |
| Часовая зона повторения | **Локальная зона преподавателя** |

## Технические сбои и права ученика

| Причина | Права ученика / действие |
|---|---|
| Неисправность со стороны ученика, преподаватель был готов работать | Потерянное время **по умолчанию считается использованным**; возможное уважительное исключение рассматривает руководитель. |
| Неисправность со стороны преподавателя | Неполученные учеником минуты **компенсируются без нового списания**. |
| Неисправность платформы/инфраструктуры академии | Академия **организует компенсацию** неполученного времени. |
| Не удалось надёжно установить источник | Спорное время **не списывается автоматически**, кейс передаётся руководителю после сбора данных менеджером. |

## Технические сбои и вознаграждение

| Ситуация | Начисление преподавателю |
|---|---|
| Сбой ученика при готовности преподавателя провести весь урок | **Полная стандартная оплата** по применимому личному тарифу. |
| Сбой преподавателя | За **фактически проведённую долю** урока; оставшаяся доля начисляется **после фактического восполнения** недостающих минут. За исправление собственной неисправности сверх полного тарифа второй раз не платить. |
| Сбой академии | Оплата за первоначально выделенное преподавателем время — **полный стандартный тариф**. Дополнительное время, фактически затраченное на компенсацию ученику, оплачивается **отдельно и пропорционально** за счёт академии. |
| Причина не установлена | Спорную часть начисления не закрывать автоматически до решения руководителя. |

## Заморозка по типу записи

| Тип записи на дату заморозки | Что происходит | Влияние на баланс | Нужно ли назначать отдельный перенос |
|---|---|---|---|
| Регулярный будущий экземпляр | Сохраняется в истории как **«Заморожено»** | Не списывается | **Нет**, после окончания действует обычное расписание |
| Ранее перенесённый урок с уже выбранной новой датой | Новая дата освобождается, право возвращается в **«Ожидает переноса»** | Одно исходное право сохраняется | **Да**, менеджер согласует новую дату |
| Ранее фактически проведённый урок | Не изменяется автоматически задним числом | Сохраняется утверждённый ранее учёт | Нет, если нет отдельного исправления ошибки |

## Связь с семьёй

| Получатель / направление | Внутренняя CRM/кабинет | Внешние автоматические e-mail/SMS/мессенджеры | Личный организационный контакт |
|---|---|---|---|
| Менеджер | Да | Допустимы по выбранной интеграции | Взаимодействует с семьёй и преподавателем |
| Преподаватель | Да | Допустимы по рабочим настройкам | Менеджер проверяет при необходимости |
| Ученик | **Только допустимые информационные сообщения** | **Нет** | Через менеджера |
| Родитель | Не создаётся отдельный родительский кабинет | **Нет** | Через менеджера |

## Перенос занятий

Минимальное время подготовки нового или перенесённого занятия задаёт LESSON_MIN_LEAD_MINUTES, по умолчанию 60 минут. Изменение ровно за 24 часа считается своевременным. Для одного оплаченного занятия ученик может дважды запросить стандартный своевременный перенос. Третий перенос и позднее изменение без потери права требуют решения директора для конкретного урока, ревизии и предложенного изменения. Переносы по инициативе академии или преподавателя и согласованная заморозка не расходуют лимит ученика. При неизвестном инициаторе прежних переносов требуется решение директора.

## Факт урока и расчёт

Преподаватель подтверждает результат в течение 24 часов после планового окончания. У занятия один актуальный основной статус. Факт, списание и выплата учитываются отдельно. Стандартная поздняя отмена учеником списывает право и даёт готовому преподавателю компенсацию 200 MDL без бонусов. Если в тот же час проведён другой урок, за него начисляется личная ставка по самостоятельному основанию. Компенсационные минуты фиксируют комментариями к занятиям. Постоянный слот в ожидании продления сохраняется. Пропущенное неоплаченное занятие само по себе не создаёт долг семьи или начисление преподавателю. Финансовый период — календарный месяц, сверку проводит менеджер, закрывает руководитель.

## Регулярное расписание

| Код | Предмет | Условие |
| --- | --- | --- |
| SCH-01 | Гибридное назначение | гибридная модель. Система подготавливает варианты совмещения ученика и преподавателя; менеджер самостоятельно принимает окончательное решение. Полностью самостоятельное автоматическое прикрепление не применяется. |
| SCH-02 | Доступность преподавателя | преподаватель заявляет **повторяющиеся недельные интервалы доступности**; дополнительно поддерживаются исключения на отдельные даты (например, отпуск или разовая недоступность). Декларация свободного времени не является автоматическим обязательством принять конкретного ученика. |
| SCH-03 | Доступность ученика | фиксируются регулярные свободные дни/часы и **предпочтительные интервалы** ученика. Предпочтения используются в поиске, но сами по себе не резервируют преподавателя. |
| SCH-04 | Ранжирование кандидатов | алгоритм ранжирует преподавателей с учётом **пересечения доступности, предпочтений, возможности обеспечить стабильное регулярное время и текущей нагрузки**. Список рекомендаций выводится менеджеру. Конкретные численные веса факторов пока не утверждались; не кодировать их как «утверждённые бизнес-константы». |
| SCH-05 | Предварительная бронь | менеджер может создать **временную бронь** на период переговоров с преподавателем/семьёй. Бронь не означает окончательного закрепления; финальное подтверждение выполняет только менеджер после внешнего согласования. |
| SCH-06 | Срок временной брони | бронь автоматически истекает через **12 часов**. **Автоматического продления нет.** По истечении времени слоты возвращаются в доступный для расчёта пул с учётом других назначений и ограничений. |
| SCH-07 | Атомарное бронирование набора | если ученику требуются несколько регулярных занятий в неделю, система резервирует **все необходимые недельные слоты одного основного преподавателя как единую операцию**. Частичное успешное закрепление недопустимо: если один обязательный слот недоступен, операция не должна оставить остальные закреплёнными как завершённый набор. |
| SCH-08 | Дата первого урока | менеджер вручную определяет дату, с которой начинает действовать новое регулярное расписание. Система не назначает первый урок только по дате заполнения анкеты. |
| SCH-09 | Срок действия регулярного расписания | регулярное недельное расписание **бессрочное**, пока не изменено или не закрыто уполномоченным сотрудником; его жизненный цикл **не привязан автоматически** к дате окончания оплаченного абонемента. |
| SCH-10 | Разовые конфликты | если исключение конкретной даты (болезнь, недоступность) затрагивает регулярное занятие, система **выявляет конфликт и передаёт менеджеру**. Автоматического произвольного переноса или смены преподавателя не происходит. |
| SCH-11 | Изменение постоянного расписания | только менеджер после внешнего согласования может менять постоянные недельные слоты. Самостоятельное одностороннее изменение учеником или преподавателем не предусмотрено. |
| SCH-12 | Момент вступления изменения в силу | согласованное изменение постоянного расписания **вступает в силу со следующего понедельника**. Существующий график до даты вступления сохраняется, если нет отдельного разового решения. Точную интерпретацию «следующего понедельника» на границе понедельника/часового пояса следует документировать на этапе реализации, а не менять в CRM без согласования. |
| SCH-13 | Если новое время занято | при невозможности желаемого нового постоянного слота система в первую очередь **предлагает другие интервалы с тем же основным преподавателем**. Менеджер выбирает согласованный вариант. |
| SCH-14 | Плановое завершение регулярного графика | менеджер может вручную задать **будущую дату окончания** повторяющегося расписания. Это закрывает действие шаблона с указанного момента, не уничтожая исторические экземпляры занятий. |
| SCH-15 | Будущие освобождающиеся слоты | менеджер может заранее закрепить слот, который станет свободен в будущем, **с указанием даты начала нового назначения**. Не допускается наложение действующих назначений на один и тот же интервал. |
| SCH-16 | Приоритет подтверждённого будущего назначения | если освобождающийся слот уже окончательно предоставлен новому ученику на будущую дату, попытка прежнего ученика вернуться **не отменяет подтверждённое будущее назначение**. Менеджер подбирает другой согласованный вариант. |
| SCH-17 | Назначение вне заявленной доступности | менеджер может разово/организационно назначить урок вне заявленных преподавателем интервалов **только после личного согласования с преподавателем**. Система предупреждает о выходе за настройки доступности и хранит след операции. Это разрешение **не отменяет запрет физического пересечения занятий**. |
| SCH-18 | Перерывы преподавателя | преподаватель указывает желаемую продолжительность перерывов, в том числе **0 минут**. Планировщик учитывает настройку при новых назначениях и **не разрушает уже подтверждённые занятия** только из-за изменения предпочтительного перерыва. |
| SCH-19 | Лимиты нагрузки | преподаватель задаёт максимальное количество уроков **за день** и **за неделю**; эти ограничения учитываются при подборе и назначении. |
| SCH-20 | Исключение из лимита нагрузки | менеджер после личного согласования с преподавателем может превысить заявленный лимит. Система выдаёт предупреждение и логирует исключение. **Накладывающиеся по времени занятия не разрешаются даже при таком исключении.** |
| SCH-21 | Локальные часовые пояса | система автоматически определяет локальный часовой пояс пользователя, показывая ему время в его зоне. В базе время должно быть однозначно нормализовано; отображение и расчёт повторений нельзя путать. |
| SCH-22 | DST и повторяющиеся занятия | регулярное занятие привязано к **локальному времени основного преподавателя**. При переходе на зимнее/летнее время (DST) у преподавателя сохраняется его местный час; отображаемое время для ученика в другой зоне может закономерно изменяться. Программно необходимо хранить IANA timezone, а не постоянное смещение UTC. |

## Действия при отклонениях

| Решение | Правило |
| --- | --- |
| **6.1** | Факт урока подтверждает преподаватель; исключения контролирует менеджер |
| **6.2** | Один основной статус урока, а не три независимые группы статусов |
| **6.3** | Подтверждение в течение 24 часов, затем задача менеджеру |
| **6.4** | Подтверждённый урок исправляет менеджер; закрытый финансовый период — разрешение руководителя |
| **7.1** | Три приоритета событий и адресация по ролям |
| **7.2** | Многоканальная архитектура, но внешняя автоматическая отправка — только сотрудникам |
| **7.3** | Автоматически отслеживать информированность преподавателя, менеджер дополнительно проверяет |
| **8.1** | При недоступности менеджера срочная задача уходит руководителю |
| **8.2** | Повторные попытки контакта, журнал, эскалация нерешённого |
| **8.3** | Резервный ручной режим при падении CRM с последующим восстановлением |
| **8.4** | Менеджер свободно редактирует организационные даты задним числом с обязательным аудитом |
| **9.2** | Компенсация поздней отмены + оплата другого проведённого урока в тот же час |
| **9.3** | Применять личный тариф, действующий в момент начала урока |
| **9.4** | Преподаватель отмечает потерянные и компенсированные минуты комментариями, сам договаривается о продлении в допустимых рамках |
| **9.5** | Организационные даты свободно изменяет менеджер, финансовые последствия вручную контролируются |
| **9.6** | ⭐-статус при неоплаченном продлении, ручной контакт менеджера, защищённый слот |
| **9.7** | Если оплаченного права нет, занятие пропускают без долга семьи или автоматического начисления. Менеджер связывается с семьёй. Финансовое решение по фактически проведённому неоплаченному уроку принимает руководитель. |
| **9.9** | Ежемесячная сверка менеджером + закрытие руководителем |
