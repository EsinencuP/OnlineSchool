Передавай кодеру один TASK. Каждый содержит повторённые общие правила, текущую основу, предметные инварианты, входные файлы, контракты, алгоритм, проверки, критерии готовности и шаблон отчёта. COMMON.md или предыдущий чат не требуется. Локальный репозиторий и актуальные исходники читать всё равно необходимо; внешние сайты — первичный справочник API/норм, не замена бизнес-требований.

Порядок: блок0 исходная точка → блок1 UI-kit/RURO → блок2 оболочка/права → блок3 ученик → блок4 преподаватель → блок5 CRM → блок6 директор/оператор/вход → блок7 сквозная приёмка. Все задачи изначально NOT_STARTED; существующий частичный код не удалять и не выдавать за пройденную приёмку.

Новая работа выполняется без публичного сайта, новых QA/staging/disposable БД, destructive suites рабочей Neon, неутверждённых KPI/P&L и самовольного production GO.
