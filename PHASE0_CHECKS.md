# Условия проверки фундамента

Для отдельного изменения запускайте нужную компиляцию, генерацию и короткие проверки затронутого поведения. Полную регрессию и повторную репетицию миграций проводите при приёмке фазы.

GitHub Actions может запускать интеграционные тесты на одноразовом сервисе PostgreSQL 18 внутри job. Для миграций и синтетических сценариев с записью рабочая база исключена. Проверку перехода с предыдущей схемы, интеграций с провайдерами и восстановления оценивают отдельно.

Для итогового допуска требуется собственная приёмка FND-GATE. Условия и команды проверок приведены в [CI](.github/workflows/ci.yml) и [инструкции к тестам](tests/README.md).
