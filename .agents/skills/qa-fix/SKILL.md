---
name: qa-fix
description: Работа разработчика по принятому пакету. Явная команда владельца K8K.
---

Запусти из корня репозитория `node qa/scripts/qa.mjs packet <cycle-id>`, подставив идентификатор цикла из запроса, когда требуется. Дождись завершения и сообщи реальный статус и путь к сохранённому результату. Делегируй изменения Developer Agent (встроенный профиль worker) в отдельном контексте, передав пакет и выбранные ID. Бери только ACCEPTED или IN_PROGRESS. Сверь требования, воспроизведи допустимым способом, исправь наименьшим изменением и проверь целевые тесты. Для подтверждения изменений сохраняй точный список и тесты. Не создавай commit без разрешения. После появления разрешённого нового commit используй `node qa/scripts/qa.mjs submit-fix <cycle-id> <fix.json>`. FIXED и READY_FOR_RETEST регистрируются этим вызовом, VERIFIED присваивает только ретест. Передай вопросы изменения требований владельцу.
