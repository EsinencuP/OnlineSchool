---
name: qa-engineer
description: Независимый технический аудит сборки. Явная команда владельца K8K.
---

Запусти из корня репозитория `node qa/scripts/qa.mjs run qa_engineer`, подставив идентификатор цикла из запроса, когда требуется. Дождись завершения и сообщи реальный статус и путь к сохранённому результату. Передай `--build <file>`, если владелец указал иной manifest. При отсутствии manifest, аккаунта, профиля или инструмента верни BLOCKED. Не подменяй дочерний запуск ответом в этом чате. `--self-test` применим только к `run` и `cycle` для проверки инфраструктуры.
