## 3. Маршруты, компоненты, данные и зависимости

### 3.1. Ученик — `apps/student-cabinet`

**Все маршруты:** `/student`, `/student/lessons`, `/student/lessons/:id`, `/student/homework`, `/student/homework/:id`, `/student/skills`, `/student/materials`, `/student/subscription`, `/student/notifications`, `/student/profile`, `/student/security`, `/student/security/change-password`, `/student/login`, `/student/suspended`; неизвестный адрес обрабатывает `RouteError`.

`router.tsx`: React Router `createBrowserRouter`, корневой фокус/смена title. `Layout.tsx`: sidebar, мобильные пять пунктов, header/bell/account, дополнительная колонка с календарём/абонементом/контактами, drawer на телефоне/планшете. Нет самостоятельного кабинета родителя.

`components.tsx`: `Panel`, `Icon`, `Empty`, `ErrorNotice`, `QueryState`, `Status`, `Pager`, `Modal`, `JoinButton`, `Countdown`, формат даты/дня, безопасные URL. В `api.ts` — TanStack Query, запросы через SDK, CSRF/idempotency и прежние переходы при утрате доступа; `ui-store.ts` — Zustand для меню.

**Источники:** собственные `getStudentMe/Dashboard/UpcomingLessons/Lessons`, выдача/версии ДЗ, опубликованные skill maps/snapshots/audit, материалы, текущий subscription/ledger/payments, notifications/unread, профиль и security sessions. Meet включается только при серверном `canJoin` и валидном URL. Режимы расписания: список/календарь, сегодня/неделя/месяц/архив. ДЗ — один список, есть необязательный select статуса, а не вкладки.

**Зависимости baseline:** React/DOM 18.3.1; Router 7.18.5; TanStack Query 5.105.0; Zustand 5.0.16; workspace SDK/shared/account-ui. Dev: Vite 7.3.7, React plugin 5.2.0, React types 18.3.31/DOM 18.3.7, Lighthouse 13.6.0. Полный manifest зафиксирован в `source-audit.json`.

### 3.2. Менеджер — `apps/manager-web`

**Все маршруты:** `/manager`, `/manager/leads`, `/manager/leads/:id`, `/manager/students`, `/manager/students/:id`, `/manager/students/:id/account`, `/manager/schedule`, `/manager/tasks`, `/manager/tasks/:id`, `/manager/login`, fallback `*`.

**Карточка ученика:** `overview`, `subscriptions`, `payments`, `schedule`, `tasks`, `notifications` — параметры URL `?tab=...`, не отдельные выдуманные маршруты. **Воронка:** список и шесть стадий board; переходы управляются существующими кнопками/командами. **Расписание:** список/день/неделя, query по периоду. **Задача:** принятие в работу, чтение завершённой, варианты решения спора ACCEPT/REJECT/ESCALATE и переноса APPROVE/DECLINE. Все эти представления сняты.

`Layout`: меню, портфолио, help, поиск Ctrl/Cmd+K, календарь/очередь, `AccountMenu`; на телефоне пять пунктов нижней навигации. `components/ui.tsx`: `State`, `ErrorBox`, `Badge`, `Field`, `Input`, `TextArea`, `Select`, `Check`, native `Dialog`, `Conflict`, `FormShell`. `business-forms.tsx`: `MoneyInput`, `PaymentForm`, `FreezeForm`, `RescheduleForm`, `DisputeForm`. Словари `ru` и `error-messages`; `money.ts` сохраняет десятичные строки через Decimal, `time.ts` — часовой пояс/Temporal. **Источники:** manager dashboard, leads/summary/options, portfolio students/card, subscriptions/distributions/payments, schedule, CRM tasks/detail, notification history. Регистрация поступления и «Передать директору» не равны подтверждению денег: это прямо объясняет существующий интерфейс. Имя SDK-метода `confirmManagerPayment` само по себе не является доказательством расширения прав менеджера.

**Зависимости baseline:** общие React/Router/Query/Zustand/workspace-версии как у ученика; decimal.js 10.6.0, Temporal polyfill 0.5.1, WebAuthn browser 14.0.0. Dev: Vite/plugin/types как выше, Vitest 4.1.12, Testing Library React 16.3.3/DOM 10.4.2/user-event 14.6.8, jsdom 30.1.3, MSW 2.15.0, axe Playwright 4.14.0, Playwright 1.64.1.

### 3.3. Преподаватель, руководитель, оператор — `apps/platform`

**Вход:** `/account`; общий session bootstrap выбирает ролевой адрес. **Преподаватель:** `/teacher` и локальные `overview/lessons/students/homework`. **Руководитель:** `/director` и `overview/lessons/students/tasks`. **Оператор:** `/operator`, только `overview` состояния компонентов. Эти локальные вкладки не имеют новых URL. Смена роли определяется серверной сессией.

`App.tsx` содержит `Login`, `Staff`, bootstrap; общий sidebar/header/account, панели, lesson/simple rows и статусы. Данные staff в локальном state/effect, не TanStack Query. Преподаватель читает только собственный workspace; директор — существующий операционный обзор; оператор — `getComponentStatus`. Endpoint `/api/v1/qa/components` — существующий API liveness, а не возвращение удалённого QA app.

`getPlatformWorkspace` возвращает расписание, назначения, выданные ДЗ и задачи. Текущий экран не подключает источник текущей ставки/начислений/выплат преподавателя, очередь сдач на проверку или финансовые KPI директора. Их нельзя «дорисовать» календарными вычислениями. Отсутствие поля в текущем Workspace не объявляется доказательством отсутствия вообще всех доменных API.

**Зависимости baseline:** React/DOM 18.3.1, workspace account-ui/SDK; Vite 7.3.7, plugin 5.2.0 и React types. Нет отдельного teacher/director/operator приложения или нового родительского кабинета.

### 3.4. Общий аккаунт — `packages/account-ui`

Единственный существующий общий пакет UI содержит **доменный** `AccountMenu`, `roleLabels`, `roleHome`, запросы каталога, CSRF-обёртку и logout/switch. Native `<details>`, Escape/внешний клик, avatar из имени. Успешная смена выполняет полный переход и BroadcastChannel для сброса прежнего контекста. В коде нет паролей каталога; серверная доступность переключения сохранена.

Baseline dependencies: React 18.3.1, SDK/shared workspace; TypeScript 6.0.3 и React types 18.3.31. Общей библиотеки **нейтральных базовых** компонентов, Radix, Storybook, TanStack Table, culori и Stylelint в baseline нет. `account-ui` нельзя бездумно импортировать как базовый kit: его entry связан с API/сессией.

### 5.3. Прочие конкретные UI-дефекты

- **A-06 / P1:** на 360px `.tabs` карточки менеджера имеет width 350px при доступных 332px; right=364px, document scrollWidth=364px. Отрицательный `margin-right: -18px` в `manager/style.css:930–934` и длинные nowrap-ссылки дают общий дефект в шести вкладках/модальных представлениях. Не маскировать `overflow-x:hidden`: сохранить доступ к каждой вкладке. [Пример](output/k8k-phase0/mgr-student-detail-360.png).
- **A-07 / P1:** бренд Academy остаётся в исходниках и HTML title; `student/router.tsx:25` ещё и устанавливает title после навигации. Это касается и прежнего локального preview, где одной замены index.html недостаточно. Учесть в фазе оболочки, не исправлять здесь.
- **A-08 / P1:** отсутствует единый контрастный token layer; цвета, статусы, размеры и fallback-шрифты расходятся. Общий статус-чип должен иметь текст и декоративную иконку; текущий текст уже исключает передачу статуса только цветом.
- **A-09 / P2:** ближайший урок ученика теряется среди равных небольших summary; disabled Meet объясняется только title, без видимого текста. Улучшить иерархию и объяснение без смены окна/права входа.
- **A-10 / высокий риск миграции:** текущие native dialogs содержат разные callback/guard-модели; финансовые формы/одноразовый секрет имеют особые жизненные циклы. Замена на Radix обязана сохранить фокус, ввод, pending/unknown-result и существующие guards, а не перенести доменные операции внутрь UI-kit.

## 6. Текущий элемент → целевой компонент packages/ui → риск поведения
