## Повтор

1. Из корня готового workspace: `node output/k8k-phase0/reproduce.mjs --build`. SDK/shared dist должны существовать и их исходник совпадать с pinned main; helper не генерирует контракты. Все файлы экспорта/сборок идут в `.codex/`.
2. Отдельно запустить `pnpm --filter @online-school/manager-web exec vite --config D:/OnlineSchool/.codex/k8k-phase0-manager-web.vite.mjs --mode mock` (путь заменить на абсолютный путь своего workspace). Порты 55173/55174/55175 для capture должны быть свободны.
3. `node output/k8k-phase0/capture.mjs`; частичный повтор — ID состояния или роль. `--pending` заполняет только неполные состояния.
4. `node output/k8k-phase0/finalize.mjs`. Исходные before-хеши продукта отражают первую рабочую сессию, поэтому для нового клона проверку сохранности нужно фиксировать отдельным manifest; не переписывать историческое evidence.

`stu-snapshot` использует явно синтетический DTO опубликованного среза; исходный test fixture отдавал пустой список. Экран выдачи пароля использует исключительно публичный MSW test-secret. Демо-каталог — публичные фиксированные тестовые аккаунты проекта, а не созданные аудитом пользователи. Никакие реальные switch-user/финансовые/внешние действия не выполняются.
