# Упрощение интерфейса K8K — 08.11.2026

Основание: прямое указание владельца убрать присутствующие признаки из списка 20 AI slop indicators. Это актуальное визуальное решение для пяти кабинетов и общего входа. Исторические акты и бизнес-правила не пересматриваются; публичный сайт остаётся отдельным проектом. Последующие задания используют это решение вместе с текущими требованиями по доступности.

| Признак | Решение в интерфейсе |
| --- | --- |
| Tags and pills | Статусы и счётчики показываются текстом с существующими смысловыми иконками, без цветных капсул; число непрочитанных сохранено |
| Excessive italicized words | Декоративный курсив в форме входа удалён вместе с рекламным блоком; остальные интерфейсы используют прямое начертание |
| Instrument Serif | В производственных кабинетах не найден; используется локальный Golos Text |
| Negative kerning | Отрицательный letter-spacing удалён из стилей кабинетов |
| Over the top detailed UI | Убраны декоративные карточки вокруг метрик и урока, фоны иконок, реклама в обеих формах входа, иллюстрация гор в прежнем кабинете ученика |
| Overusing dividers | Убраны разделители в строках списков, карточках, шапке и меню аккаунта; структура таблиц и навигации остаётся читаемой |
| Multiple color shades and opacities | Близкие оттенки объединены через токены; отдельные цвета оставлены для ошибок, предупреждений и успеха. Полупрозрачность остаётся у модального затемнения и одной тени всплывающих окон |
| Containers with borders | Убраны рамки панелей, карточек, внешней таблицы, статусов, уведомлений и всплывающих окон. Границы полей ввода, состояния выбора и клавиатурный фокус сохранены |
| Overly detailed diagrams | В целевых производственных интерфейсах не обнаружены; календарь и карта навыков остаются рабочими представлениями данных |
| Overly verbose or redundant text | Удалены рекламные блоки входа, повторяющиеся вводные фразы и дублирующая помощь профиля; объяснения прав доступа, ошибок, MFA и свежести данных сохранены |
| Code breadcrumbs | Декоративные цепочки путей исходников в интерфейсе не обнаружены; настоящие ссылки на уроки и документы сохранены |
| Section numbering | Убраны декоративные номера этапов навыков; порядок этапов, нумерация страниц и календарные даты сохранены |
| Eyebrows | Удалены надзаголовки, подпись «Рабочее пространство» и рекламные подписи. Счётчик портфеля переведён в обычные метаданные |
| Dithering | В целевых интерфейсах не обнаружен |
| ASCII images | В целевых интерфейсах не обнаружены |
| Squiggles | Декоративная иллюстрация гор удалена; прочие волнистые украшения не обнаружены |
| Excessive monospaced | Не обнаружен; моноширинный шрифт оставлен только для разового пароля менеджера, где важна различимость символов |
| All caps subtitles | Принудительный uppercase в стилях кабинетов удалён; API, MFA, RU/RO и обозначения валют остаются содержательными сокращениями |
| Gradient backgrounds | Все найденные градиенты кабинетов заменены однотонными поверхностями; удалены градиенты и орнамент рекламного блока входа |
| Periods in titles | Рекламные заголовки с точками удалены; интерфейсные заголовки без конечных точек. Пунктуация сообщений, дат и пользовательских данных не изменяется |

Изменения находятся в общей библиотеке UI, общем меню аккаунта и трёх приложениях кабинетов. Переключатель ui.k8k не включается автоматически: новые CSS-переменные доступны также прежней оболочке; fallback ученика и общего входа проверены отдельно.
