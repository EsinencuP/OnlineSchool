# TASK-024 — проверенные контракты для TASK-025 и TASK-026

- `getStudentSubjects(options)` читает `GET /api/v1/student/subjects` без параметров. Предлагаемый ключ для первого потребителя — `['student','subjects']`. Его можно читать через `useStudentQuery`; новая периодическая политика этой задачей не добавлена. Дата источника — `generatedAt`, время получения берётся из query cache. [DTO](../../../apps/api/src/student/subjects/subjects.dto.ts) · [SDK](../../../packages/api-contracts/src/generated/client.ts)
- `items` упорядочены сервером по `subjectId`. `enrollmentIds` перечисляют собственные начавшиеся enrollment этого предмета. В `subscriptions` предпочтительный план первый. `subscriptionId` — финансовый anchor для `getStudentSubscription`, `getStudentSubscriptionPayments` и `getStudentSubscriptionLedger`, а также текущего URL `/student/subscription?subscriptionId=…`. `managerSubscriptionId` обозначает группу периодов. [Контракт](contracts.json)
- `paidLessonsRemaining` — подтверждённое количество либо `null` при неизвестности. `temporaryAdmission` отдельно содержит `maxLessons`, `lessonsRemaining` и точный `validUntil`. Свойства `reasonCode` пригодны для локализации. Текст решения директора отсутствует в DTO. [Правила проекции](design-note.md)
- `canViewHomework` и `canViewMaterials` отражают существующие выдачи. `canOpenLessons` обозначает доступность чтения и может быть true для истории. Для кнопки Meet нужен актуальный `canJoin` отдельного урока. Смена сессии и 401/402/403 продолжают проходить через текущую границу кабинета. [Guard](../../../apps/api/src/student/active-subscription.guard.ts) · [Урок](../../../apps/api/src/student/lessons/lessons.service.ts)

Адресные unit/HTTP/SDK проверки пройдены. Исполнение SQL и план запроса на PostgreSQL остаются отдельной проверкой при явно разрешённом read-only доступе. [Отчёт](report.md)
