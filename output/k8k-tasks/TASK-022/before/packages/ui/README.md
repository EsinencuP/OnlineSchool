# K8K UI — оболочка фазы 2

Нейтральный ESM/React 18 пакет без SDK, запросов, доменных команд и решений о правах. Минимальная основа фазы 2; полный каталог компонентов, Radix, Storybook, culori и Stylelint фазы 1 этим изменением не объявляются завершёнными.

Импортируйте `@online-school/ui/style.css` после старого CSS. `k8kEnabled`: `?ui.k8k=1` включает новую оболочку, `?ui.k8k=0` возвращает прежнюю. Выбор хранится в sessionStorage текущего origin; при закрытом storage работает прямой URL. Флаг не предоставляет права и не меняет capabilities.

`AppShell` использует стабильный `roleNavigation`. Приложение передаёт существующий router Link или обработчик локальной staff-вкладки через `renderNavigation`; компонент не придумывает URL. От 1024 px — Sidebar; ниже — BottomNav и немодальное раскрываемое меню. Данные не являются зависимостью эффекта фокуса. AppShell принимает `timeZone` из текущего `/me`; staff сохраняет существующее Europe/Chisinau.

`StateBoundary` принимает discriminated union девяти состояний VIS-11. Ready/stale/pending сохраняют контейнер данных; forbidden/session-expired не рендерят children. Subscription-limited сохраняет доступные предметы: UI не определяет, какой предмет закрыт. `retryRead` предназначен только для чтения; в pending/unknown-result кнопки повторения нет. Компонент не заменяет обработчики 401/403, CSRF и idempotency.

`FreshnessLabel` показывает время успешного чтения либо явную неизвестность. Это не время бизнес-подтверждения и не гарантия свежести ledger. Клиентский dataUpdatedAt не объявляется серверным временем.

`useContextRefresh` вызывает только повторное чтение. Скрытая вкладка, офлайн, ввод, открытый диалог/меню аккаунта откладывают его; окончание ввода возобновляет отложенное чтение. Возврат/focus/online дедуплицируются. TanStack Query обновляет только активные оперативные ключи; auth-read и post-command invalidation остаются прежними.

Предварительная рекомендация за ui.k8k: 60 секунд для оперативных данных, 15 для открытой карточки урока ученика, 120 до предупреждения о возрасте оперативной проекции. Финансы, опубликованные навыки и архив не получают периодического опроса из новой политики. Точные интервалы VIS-06 требуют решения владельца; это не серверные таймеры/эскалация/SLA.

`PriorityEvents` требует **оба** условия: `enabled=true` и `source`. В AppShell `priorityEnabled` по умолчанию false. В текущих DTO нет авторитетного уровня критичности/выбора primary, поэтому продуктовые адаптеры флаг не включают. Просрочка сама по себе не критичность. При готовом источнике primary выбирает разрешённый адаптер; criticalCount включает всю очередь; queueAction ведёт в существующий сценарий. Показ/переход не отправляют read/resolve/claim-команды. Синтетический пример есть только в tests/browser.

Проверки из корня: `pnpm --filter @online-school/ui build`, `pnpm --filter @online-school/ui test`, `pnpm --filter @online-school/ui lint`. После сборки трёх приложений: `node scripts/k8k-phase2-browser.mjs` и `node scripts/k8k-phase2-bundle.mjs`. Browser harness использует только fixtures/MSW и блокирует внешние запросы.
