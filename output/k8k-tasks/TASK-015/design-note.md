# TASK-015 — design note

Подключение account-ui → @online-school/ui (workspace:*) к существующим useLocale, translate и LanguageSelector. AppShell сохраняет account slot и передаёт его Header. Один селектор в открытом AccountMenu, один на каждой точке входа. AppShell больше не создаёт второй селектор. AccountMenu получает optional onLogout(): Promise<boolean> для существующей очистки/редиректа student и manager. Demo switch, транспорт аккаунта, SDK и roleHome остаются в account-ui. Дополнительные logout controls удаляются. accountRoleLabel(locale, role) переиспользует ключи account.role.*; прежний roleLabels остаётся совместимым.

NavigationItem сохраняет id, href, label и shortLabel. В roleNavigation добавляются типизированные labelKey и optional compactLabelKey для отображения по роли. AppShell и существующие legacy chrome используют словарь. Новые ключи account.*, nav.*, chrome.* добавляются в оба словаря. Никаких новых DTO, operations или session state. Для языка не запускается навигация, повтор команды или перемонтирование формы.

Инвентарь до изменений: Sidebar, BottomNav, StateBoundary, PriorityEvents, FreshnessLabel, StatusChip, Avatar, Dialog close, Toast и Calendar имеют typed defaults. Пробелы: AppShell выбирает подпись по id и теряет контекст роли; account-ui хранит русский текст меню, статуса, ошибок и ролей; header/footer и sidebar shortcuts в приложениях частично RU. Публичные props с caller-owned текстом сохраняются. Контент уроков, сообщения и значения серверных кодов не переводятся.
Уточнение результата onLogout(): Promise<AccountLogoutOutcome>, где AccountLogoutOutcome — ended | rejected | unknown. При неизвестном исходе account-ui оставляет переход к проверке текущей сессии и блокирует повтор записи. Прежние idempotency/CSRF и обработчики отзыва сессии сохраняются.
