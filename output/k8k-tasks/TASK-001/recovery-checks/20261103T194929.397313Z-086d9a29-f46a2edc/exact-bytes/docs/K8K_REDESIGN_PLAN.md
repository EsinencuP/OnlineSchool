## Контрактная дисциплина

Сначала read-model/ACL и адресные проверки, затем OpenAPI/SDK штатной генерацией, затем UI. Не добавлять вторые ledger, клиентские формулы доступа/зарплаты или фиктивные fallback-данные. Все мутации сохраняют CSRF, idempotency и unknown-result без автоповтора.

## Приёмка

Meet −10m/T0/перенос/нет ссылки/stale; независимые предметы/заморозка/допуск; медленные черновики; педагогическая публикация; director-only деньги; выход/смена роли/вторая вкладка/поздний ответ; RU/RO + 4 ширины + клавиатура/screen reader/zoom/reduced motion; ≤250KiB gzip на маршрут. Автоматический axe не заменяет ручную WCAG2.2AA проверку.

## Ограничения выпуска

Флаг ui.k8k сохраняет старый вид до ролевой приёмки. Dependencies только по потребности, pinned, проверенные license/peer/age/audit/bundle. Палитра provisional. Нет .ics/сохранённых фильтров/PWA/offline/dark mode/новых внешних автонапоминаний. LEGAL-01, FIN-LEGAL-01, Meet OAuth/POC/G4 и FND-GATE не закрываются UI-тестами. Единственная рабочая Neon main не используется для разрушительных suites.

## Исходное доказательство

output/k8k-implementation/baseline: HEAD, SHA256 исходников, git status и binary patch tracked-изменений. Незакоммиченный ученический preview сохранён. Исторические output/k8k-phase* не считаются новым прогоном.
