# Блок5 — Абонементы, финансы и исключения

Модуль выполняется отдельными заданиями по порядку. Этот индекс не заменяет текст TASK; каждый файл содержит собственный контекст и правила.

- [TASK-055 — Абонементы CRM: направление, продление, заморозка и разморозка](../TASK-055.md). Исходно: Рабочие UI/API существуют; часть кнопок зависит лишь от статуса, UI жёстко пишет60дней и выбирает готовые распределения из отдельных страниц. Нужна функциональная миграция на K8K/actions без изменения финансовых правил.
- [TASK-056 — Поступления, распределения и директорские допуски: точный финансовый UI](../TASK-056.md). Исходно: Существуют receipt/distribution forms и Finance facade; manager-confirm уже отправляет на approval. Требуются K8K/actions, точные подписи всех состояний и полная демонстрация partial admission без обхода директора.
- [TASK-057 — Споры о списании и исключения расписания без обхода директора](../TASK-057.md). Исходно: Основные API/UI tasks/reschedule/dispute существуют; текущие pending director/manual finance состояния нужно ясно показать. Нельзя возвращаться к историческому самостоятельному ACCEPT менеджером.

Выход модуля: критерии каждого TASK и доступные по ссылкам отчёты; gate не считается пройденным по наличию исходного кода.
