# K8K Academy — задания AI-кодеру

Редакция1.0 от03.11.2026. **76 отдельных TASK,8 блоков**, каждый с повторённым контекстом, правилами, локальными источниками, входными файлами, контрактами, алгоритмом, негативными сценариями и Definition of Done.

## Как использовать

1. Начни с [TASK-001](TASK-001.md). Проверь prerequisites, выполни ровно это задание, сохрани отчёт.
2. Передавай кодеру содержимое **одного** следующего TASK либо его файл. COMMON.md, старая переписка и чужой чат для восстановления контекста не нужны.
3. Локальные исходники и требования читаются по точным ссылкам внутри задания; важные правила уже повторены прямо в нём. Сайты — первичный справочник, не источник дополнительных бизнес-решений.
4. Наличие частичной реализации означает «ревью → завершить → проверить», а не «переписать» и не «пропустить». Исходный статус описывает03.11.2026; статус выполнения изначально NOT_STARTED у всех заданий.
5. Кодер обновляет [журнал](EXECUTION_LOG.md), матрицу и `output/k8k-tasks/TASK-NNN/report.md`, затем останавливается. После проверки результата владелец выдаёт следующий TASK.
6. Если predecessor реально не готов, кодер указывает точный недостающий интерфейс/артефакт. Не заменяет его mock в product code, выдуманным API или повторным вопросом по закрытому решению.

**Короткая команда для нового чата:**

```text
Рабочий репозиторий D:/OnlineSchool. Выполни только docs/k8k-redesign-tasks/TASK-001.md.
Задание самодостаточно: прочитай его целиком, проверь локальные источники и фактический код.
Сохрани существующие dirty/untracked изменения. Не выполняй следующий TASK автоматически.
В конце дай отчёт по заданному шаблону с реальными проверками, остатками и путями доказательств.
```

Меняй номер001 на выданный владельцем номер. Весь пакет — декомпозиция утверждённого плана, не факт реализации и не разрешение публиковать/менять рабочую БД.

## Состав пакета

- [Все TASK одним файлом](TASKS_ALL.md) — для поиска/экспорта, не инструкция на один запуск.
- [Источники](SOURCES.md) — действующие/исторические документы, проверенные официальные сайты и ограничения их использования.
- [Журнал исполнения](EXECUTION_LOG.md) —76 строк; заполнение по факту.
- [Машинный manifest](manifest.json) — IDs, зависимости, scope, entrypoints и контрольные суммы исходной редакции. После изменения задания пересчитать checksum в рамках новой редакции.
- [План проекта](../K8K_REDESIGN_PLAN.md), [текущий статус](../K8K_IMPLEMENTATION_STATUS.md), [матрица](../K8K_REQUIREMENTS_MATRIX.md).

Проверка пакета: `python scripts/validate-k8k-taskpack.py` из корня. Она проверяет документацию, не тестирует продукт и не обращается к БД/сети.
