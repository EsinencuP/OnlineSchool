- [TASK-062 — Директор: подтверждённые обязательства, отдельный реестр споров и корректное закрытие периода OPS-02/B](../TASK-062.md). Полной period detail/read-модели и UI нет; соответствие OPS-02 пока не доказано.
- [TASK-063 — Директор: честный операционный главный экран и RU/RO-приёмка рабочего кабинета](../TASK-063.md). Исходно: Сейчас директор видит overview школы, расписание, учеников/назначения и открытые задачи. Все VIS12 DIR-01…06 имеют conditional scope, DIR-07 POST-MVP.
