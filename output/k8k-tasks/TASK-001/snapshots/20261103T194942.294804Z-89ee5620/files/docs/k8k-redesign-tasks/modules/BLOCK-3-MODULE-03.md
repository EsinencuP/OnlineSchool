# Блок3 — Уроки и домашние задания

Модуль выполняется отдельными заданиями по порядку. Этот индекс не заменяет текст TASK; каждый файл содержит собственный контекст и правила.

- [TASK-029 — Календарь, карточка урока, история, перенос и предметный спор](../TASK-029.md). Исходно: Частично: list/calendar/detail и reschedule form работают; серверная история/спор существуют, но полный связанный UI и фактические snapshots/deduction/canDispute ещё нужно довести.
- [TASK-030 — Редизайн домашних заданий без потери надёжности редактора](../TASK-030.md). Исходно: Рабочий редактор уже реализован: debounce2s, последовательные server saves, upload intent, версии, route blocker. Требуется перенос на общий UI-kit, полная RU/RO и проверка неизвестного результата без переписывания жизненного цикла.

Выход модуля: критерии каждого TASK и доступные по ссылкам отчёты; gate не считается пройденным по наличию исходного кода.
