# TASK-025 — передача

- K8K использует действующий opt-in `ui.k8k=1`. Хаб `/student/subjects?subjectId=…` и помощь `/student/help` находятся под `StudentLayout`. На хабе запрашивается один `GET /api/v1/student/subjects` с ключом `['student', 'subjects']`. Активный ключ участвует в общей политике оперативного чтения.
- `subjectId` выбирает предмет только из собственного снимка. `/student/materials` и `/student/skills` получают этот селектор в своих GET. Страницы материалов и их total приходят из одного запроса. Право читать карту дополнительно проверяет существующий skills endpoint по собственному enrollment.
- `fromSubjectId` сохраняет контекст возврата из ДЗ, расписания и деталей абонемента. Он не передаётся в API и сверяется с предметной проекцией перед показом ссылки возврата. В ссылке на абонемент `subscriptionId` обозначает финансовый период.
- После подтверждения autosave обновляется черновик существующей карточки ДЗ в кэше этой сессии. Очередь, guards, endpoint и idempotency прежние. Позицию при Back/Forward восстанавливает роутер K8K.
- TASK-026 получает финансовый переход и `StudentSubjectSubscriptionDto` из TASK-024. UI остатка, срока и раздельного лимита допуска остаётся в TASK-026. TASK-027 получает `/student/help` и `StudentManagerCard`, работающие с текущим `me.managerContacts`.
- Контрактные продолжения при необходимости предметного фильтра. TASK-029 — серверная фильтрация расписания и истории с сохранением total. TASK-030 — предметный фильтр единого списка ДЗ при наличии контракта. TASK-031 — фильтр опубликованных срезов и их пагинации. Общие списки доступны сейчас. Перенос работает по существующим условиям карточки урока. UI спора относится к TASK-029.
- TASK-034 отвечает за полную RU/RO локализацию прежних страниц. В TASK-025 проверяются новая главная, хаб, помощь и добавленные элементы навигации.

## Сохранённые маршруты

| Маршрут | Переход |
|---|---|
| `/student` | Главная и колокольчик |
| `/student/lessons`, `/student/lessons/:id` | Расписание, карточка урока, переход из контекста предмета |
| `/student/homework`, `/student/homework/:id` | Общий список, карточка и черновик, возврат к предмету |
| `/student/skills`, `/student/reports` | Путь знаний, общие срезы и опубликованные отчёты |
| `/student/materials`, `/student/subscription` | Материалы, абонемент с действующим финансовым селектором |
| `/student/profile`, `/student/security` | Ссылки из AccountMenu |
| `/student/notifications` | В K8K перенаправление на `/student?events=1`. В прежнем интерфейсе адресует исходную страницу |
| `/student/login`, `/student/suspended`, `/student/security/change-password` | Существующие переходы сессии, доступа и первоначального пароля |
