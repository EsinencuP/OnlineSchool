# TASK-026 — передача

- Главная K8K и хаб используют `getStudentSubjects` и ключ `['student','subjects']`. Главная показывает первый серверный план каждого предмета. В карточке выбранного предмета доступны все возвращённые планы.
- Маршруты сохранены. `/student`, `/student/subjects?subjectId=…`, `/student/subscription` и `/student/subscription?subscriptionId=…`. Дополнительный `fromSubjectId` сохраняет навигационный контекст. Продление ведёт на `/student/help` к существующим официальным контактам. TASK-027 расширяет проекцию контактов.
- Одинаковый финансовый якорь отправляется в GET деталей, платежей и истории. `managerSubscriptionId` используется для сопоставления ответа со снимком при выборе по умолчанию. Он не становится параметром финансового GET. Состояние страниц и React Query изолированы по якорю.
- `paidLessonsRemaining`, `temporaryAdmission`, сумма распределения и количество начисленных занятий показываются раздельно. Разрешённые материалы и ДЗ при заморозке приходят из capabilities. Для Meet нужна серверная eligibility конкретного урока.
- Для будущего периода `getStudentSubscription` возвращает `NONE`. История подтверждённых платежей всё ещё запрашивается по исходному якорю. Будущие периоды не перечисляются TASK-024 до начала. Старая ссылка поддерживается через проверку владения сервером.
- Отсутствующая сторона исторического снимка списания возвращается как `null`. Записанные суммы, прежние начисления, отмены, заморозки и порядок событий сохраняют серверную семантику. Исторические данные без сохранившегося источника не восстанавливаются.
- В TASK-035 передаётся ролевой gate. В старом интерфейсе оставлен прежний обзор, пока ролевой прогон не подтверждён. В TASK-027 передаётся ссылка из деталей на помощь. Проверка PostgreSQL и рабочего ролевого сценария остаётся отдельной.
