# TASK-020 — design note

Base `60e2a0c47cbcc744dc658a85f386833146e836b3` plus verified TASK-019 dirty changes. Existing Platform `section` query and pushState/popstate remain the entry points. Staff list links preserve `section`, `ui.k8k` and stable `filter` enums. A detail adds UUID `id`; arbitrary private text is not stored in the URL. The list filters the returned server sample and keeps its coverage notice. Manager detail URLs and the Student legacy notification redirect remain existing entry points.

New operation `getPlatformWorkspaceDetail(section, id)` on `GET /api/v1/platform/workspace/:section/:id`. Response `WorkspaceDetailDto` has `actorContext` and `item` (one of `WorkspaceLessonDetailDto`, `WorkspaceStudentDetailDto`, `WorkspaceHomeworkDto`, `WorkspaceTaskDto`). It reads one scoped object in a read-only transaction, with existing actor and role policies and neutral 404 for absent/out-of-scope records. No schema or write. Teacher lesson/homework scope follows assigned teacher/issuer. Student scope follows an active teaching assignment. Director sees the school lesson/student view and active manager tasks. Operator has only health.

`StaffCabinet`, `StaffWorkspace`, `StaffDetail` separate shell, list, and object read. Internal `useStaffNavigation` shares push/pop handling and records scroll by history entry. Explicit links focus the heading after commit. Reload, locale, and background refresh leave focus alone. `AppShell.mobileMore` opts the Platform staff surfaces into a bottom More trigger using the existing Escape/focus-return behavior.
