## Настройка и проверка

Настоящие API и worker используют существующую Neon main, PostgreSQL 18.
Миграции выполняются direct credential при сборке; запросы — ограниченной pooled ролью.
21 миграция включает forward-only права UPDATE только нужных полей пароля,
подтверждённого email, начальной смены пароля и профиля. SQL guards сохранены.
Сборка дополнительно проверяет эти права через runtime role в read-only транзакции.

Vercel передаёт именованные rewrite captures в query. Граница serverless заново
читает клиентские параметры из URL и исключает только совпадающий служебный
`__vercel_api_path`; неизвестные параметры и дубликаты остаются для строгих DTO.
Три целевых теста и компиляция API прошли.

Рабочий браузер подтвердил вход, смену временного пароля, 11 прямых
маршрутов, сохранение профиля, чтение уведомления, мобильную ширину 390 px.
Финальная проверка: 0 ошибок JavaScript и 0 неуспешных запросов API.
Отдельно реально выполнены автосохранение ДЗ, browser PUT в Neon Storage,
серверная проверка файла и сдача. Сдача сохранена в БД; баланс остался 6.
API и worker health отвечают ok. Полные локальные снимки находятся в
`output/stu12-deploy/`, исключены из графа и source export.

## TEST-данные и доступ

Владелец отдельно согласовал набор, описанный в STUDENT_TEST_DATA_PLAN.md:
6 занятий на 30 дней (до 27 ноября 2026), три будущих урока, ДЗ, четыре навыка
и цель. Единственная демонстрационная оплата 120 MDL имеет маркер
OWNER-DEMO-NO-REAL-PAYMENT. Она находится в общей main и может попасть в отчёты.
Реального перевода, проведённых уроков, списаний и зарплаты не создавали.
Тестовое ДЗ с owner-test.txt уже сдано при проверке.

Пароль находится только в локальном приватном файле
`.identity-ops/STUDENT_CABINET_ACCESS.txt`. Он не входит в Git, source export
или браузерный bundle. Временные provisioning/inspection flags и password hash
удалены из project env; финальный deployment создан после их удаления.
Provisioning не имеет HTTP endpoint, требует отдельного маркера согласия,
правильного project ID и TTL до 30 минут; повторный запуск не дублирует данные.

Resend не подключён по решению владельца: отправка кода смены email пока
недоступна. Meet-встреча не создана; кнопка входа в урок остаётся недоступной
до реальной ссылки/разрешённого окна. Материалы преподавателя и отчёты пусты,
если преподаватель их не публиковал. Чужие/исторические записи не подменялись.

Это целевая проверка рабочего кабинета, не закрытие FND-GATE, общего regression
или ручной приёмки владельцем. Исторические fixture/Lighthouse evidence STU-12
сохранены отдельно и не объявляются проверкой настоящей БД.
