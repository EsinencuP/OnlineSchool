# Данные для проверки кабинета владельцем

28 октября 2026. Read-only проверка существующей `online_school` подтвердила:
20 применённых миграций, 0 учеников, 0 активных ученических аккаунтов,
0 абонементов, 0 платежей, 0 уроков и 0 ДЗ. Один преподаватель и директор уже есть.

Для самостоятельной проверки кабинета предлагается один отдельный набор:

- логин `themrack26@gmail.com`, имя `[TEST] Кабинет владельца`;
- новый временный пароль, передаваемый владельцу через локальный закрытый файл;
- один отдельный `[TEST]` преподаватель и предмет;
- абонемент `[TEST] STU12 — 6 занятий`, срок 30 дней;
- одна **демонстрационная**, не реальная оплата **120 MDL**, распределённая на
  этот тестовый абонемент; provider/external reference и основания содержат
  `OWNER-DEMO-NO-REAL-PAYMENT`;
- 6 подтверждённых тестовых прав на занятия, без проведённых уроков/списаний/зарплаты;
- 3 будущих урока и 1 ДЗ для проверки черновика, загрузки и сдачи;
- 4 навыка и одна учебная цель. Ни Meet-встреча, ни реальные контакты не выдумываются.

Учётная запись активируется по существующим SQL-ограничениям. Политику допуска,
guards и финансовые проверки не ослабляем. Данные добавляются в одной транзакции
с фиксированными UUID и аудитом; повторный запуск не меняет пароль и не дублирует
платёж/права. Существующие записи не изменяются.

Поскольку проект использует единственную рабочую БД, тестовые финансовые записи
будут находиться в ней и могут попасть в общие отчёты. Это требует отдельного
выбора владельца: согласовать явный TEST-набор или использовать реальные
подтверждённые финансовые основания. До выбора набор не создаётся.
