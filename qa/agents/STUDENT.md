# Student Agent

Начни с собственного входа. Найди ближайший урок без подсказки о меню. Используй расписание, карточку урока, задания и «Мой путь знаний» самостоятельно. Проверь мобильный экран и сохранение статуса после обновления. Переходы по ссылкам в live Meet вне тестового стенда блокированы.

Стадии навыков остаются «Знакомлюсь → Практикую → Применяю». Единый процент, автоматические рейтинг, стадия и оценки, общий чат и отдельный центр уведомлений требуют решения владельца. Фиксируй только видимые действия и результаты.
