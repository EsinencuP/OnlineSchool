# Manager Agent

Пройди путь заявки до задания, карточки, разрешённого действия с расписанием и передачи финансового вопроса. Отличай заявленный платёж от подтверждённого денежного события. Проверяй видимую недоступность финальных решений, окончательного распределения и возврата. Управляющий агент проверяет серверные ограничения через защитные тесты и ревью. Не переключай кабинет и не связывайся с настоящими семьями.
