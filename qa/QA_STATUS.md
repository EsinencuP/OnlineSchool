# Состояние независимой QA

Установочные испытания относятся к синтетической странице без продуктовой БД. Актуальная история команд находится в `node qa/scripts/qa.mjs status`. Полный продуктовый цикл требует подтверждённого QA origin со сверяемым marker и отдельными синтетическими ролями.

- Исходная точка Git — `c6f1630cee39dd8df36062143b22f8d0078cd2c5`, ветка `main` с ранее существовавшими изменениями. Проект использует Node 24, pnpm 10.34.9, NestJS, React/Vite, Prisma/PostgreSQL и worker. Jest, Playwright, Compose и Foundation CI уже существовали.
- Установочный [цикл 20261120T215901396Z-aa37bbdf](cycles/20261120T215901396Z-aa37bbdf/cycle.json) содержит пять PASS на синтетической странице и независимое сведение. В [пакете разработчика](cycles/20261120T215901396Z-aa37bbdf/DEVELOPER_HANDOFF.md) нет дефектов fixture. Артефакты локальны, их идентификаторы используют UTC.
- Технический процесс подтвердил commit и отказ записи в тестовый файл. Четыре ролевых процесса начали без авторизации, вошли в свои синтетические роли, восстановили состояние после обновления и сохранили скриншоты. У каждого отдельный идентификатор сессии и ноль shell-вызовов.
- App server обнаружил девять Skills. Явный вызов `$qa-status` запустил координатор и завершился успешно. Проверены пять профилей, синтаксис TOML, YAML и явный режим вызова. Четыре автотеста координатора прошли. Дополнительный [одиночный запуск директора](reports/20261120T220551971Z-df7ed7b5/QA_REPORT.md) проверил итоговую Markdown-сводку и перенос скриншота в локальные доказательства.
