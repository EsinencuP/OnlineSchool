# Матрица DIRECTOR

Для каждого сценария проверь путь через интерфейс, наблюдаемое состояние и результат обновления, где он применим. После входа подтвердить свою роль. Изменения допустимы только на синтетическом стенде с подтверждённой политикой записи. При недоступном fixture укажи BLOCKED и причину. Для основных экранов повтори на узкой ширине и проверь клавиатуру.
