# Матрица доступности

| ID | Сценарий | Что наблюдать |
|---|---|---|
| A11Y-01 | Вход, навигация и формы клавиатурой | Порядок фокуса, видимый фокус, Tab, Shift+Tab, Enter, Escape |
| A11Y-02 | Диалоги, меню и уведомления | Имя, роль, состояние, фокус внутри и возврат, объявления ошибок |
| A11Y-03 | Узкая ширина и масштаб | Reflow, вложенный скролл, читаемость, размер действий |
| A11Y-04 | Контраст и состояния | WCAG AA по применимым критериям, различимость без цвета |
| A11Y-05 | RU/RO, reduced motion и screen reader | Язык, доступные имена, уважение настроек ОС |
| A11Y-06 | Автоматическая и ручная проверка | Существующий test:a11y и ручное прохождение, где автоматизация неполна |
