# Матрица производительности

| ID | Проверка | Доказательство |
|---|---|---|
| PERF-01 | Login и Dashboard по ролям | Среда, build, размер данных, время cold/warm, повторяемость |
| PERF-02 | Список и обновление | Запросы, объем, пагинация, cache hit и пустые состояния |
| PERF-03 | Расписание и компоненты интерфейса | Существующие scripts/k8k-*budget*, рендеры и вес |
| PERF-04 | Backend, БД и worker | Известные измерения безопасных fixtures, индексы, N+1, повторный вызов |
| PERF-05 | Регрессия с ростом данных | Сравнение на разрешённом отдельном стенде, одинаковый профиль нагрузки |

Используй только утверждённый бюджет. При его отсутствии сохрани измерение и основания сравнения без нового SLA. Не нагружай production или рабочую БД.
